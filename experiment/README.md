Text-to-SQL studies. All final results use the OpenAI Responses API with Luna/high.

## Setup

Run these commands from `experiment/`:

```powershell
uv sync --frozen
```

Copy `.env.example` to `.env`. Supply an API key for model runs.
The optional [Codex adapter](codex_proxy/README.md) supports development tests.
All reported benchmark results use the OpenAI Responses API.

### Frozen-run validation

The BIRD runners and analysis tools resolve recorded experiment paths locally.
Saved manifests bind each run to its inputs, settings and file hashes.
Git preserves the bytes of files in `manifests/`, including their line endings,
because frozen records refer to their SHA-256 checksums.

Freeze validation checks file contents as well as model settings. A changed
implementation requires a new freeze for a new run; an existing run can resume
only with its original implementation and run contract. Published results and
offline analysis do not require another benchmark run.

## Offline checks

The test suites use local fixtures and make no paid model calls. First obtain
the pinned public Mini-Interact evaluator using the
[source setup instructions](readiness/README.md#public-source-dependencies).
The preparation and dataset-integrity commands additionally need the local
data listed in that guide. The public-outcome analysis below needs only
the tracked outcome projection.

```powershell
uv run --frozen python -m unittest discover -s interaction/tests -v
uv run --frozen python -m unittest discover -s readiness -p "test_*.py" -v
uv run --frozen python -m unittest codex_proxy.test_runner -v
uv run --frozen ruff check interaction readiness codex_proxy
uv run --frozen python -m readiness.prepare_mini_interact
uv run --frozen python -m readiness.check_datasets
```

The final command checks BIRD data hashes, the Mini-Interact release and the
private merge. It writes its findings to `runs/dataset-readiness.json`.

## Reproduce analyses without model calls

Write analysis outputs to a separate directory:

```powershell
New-Item -ItemType Directory -Force runs/replay-check | Out-Null

uv run --frozen python -m interaction.analyze_bird_dev_clarification_value_public `
  --projection manifests/api-bird-dev-clarification-value-v1-public-outcomes-2026-08-30.json `
  --output runs/replay-check/primary-analysis.json

uv run --frozen python -m interaction.analyze_bird_dev_matched `
  --run-root runs/api-bird-dev-matched-v4-full1534-luna-high-20260830 `
  --output runs/replay-check/supporting-analysis.json `
  --sensitivity-exclusions manifests/bird-dev-matched-v4-full1534.json

uv run --frozen python -m interaction.analyze_standardized_results `
  runs/api-official-mini-stress-comparison-v2-luna-high-reserve240-20260830 `
  --output-json runs/replay-check/mini-analysis.json `
  --output-markdown runs/replay-check/mini-analysis.md `
  --figure-dir runs/replay-check/figures `
  --bootstrap-samples 10000 --bootstrap-seed 20260822
```

The primary public projection supports replay without private trajectories.
The supporting and Mini-Interact commands require the retained local run files.
The BIRD figures are generated by `interaction.plot_bird_dev_clarification_value`
and `interaction.plot_bird_dev_matched`.

## Directory structure

- `interaction/`: final controllers, shared runtime, analysis and tests.
- `readiness/`: original-BIRD verification and Mini-Interact merge/evaluator checks.
- `manifests/`: final freezes, aggregate results, development selections and provenance.
- `notes/`: study protocols, results, scoring details and worked examples.
- `figures/`: generated result plots.
- `datasets/` and `runs/`: local, Git-ignored data and trajectories.

Private Mini-Interact content, API credentials, raw trajectories and local
environments must stay outside Git.
